# Code of Conduct — File Browser Next

File Browser Next is a community-driven open source project. Everyone who contributes, reports issues, reviews code, or participates in discussions is part of this project.

This code of conduct applies to all project spaces: GitHub issues, pull requests, discussions, commit messages, and any other channel tied to File Browser Next.

## Our Commitment

We are committed to keeping participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, nationality, personal appearance, religion, or sexual identity and orientation.

We build software together. That means listening to each other, disagreeing constructively, and treating every contributor as a peer — whether they are submitting their first issue or their hundredth pull request.

## What We Expect

Behavior that makes this project a good place to contribute:

- Being direct, constructive, and respectful in code reviews and discussions
- Welcoming contributors of all skill levels
- Giving and receiving feedback without taking it personally
- Acknowledging mistakes and moving forward
- Focusing on the technical problem, not on the person

Behavior that is not acceptable:

- Harassment, insults, or personal attacks of any kind
- Discriminatory jokes or language based on ethnicity, gender, religion, disability, or any other personal characteristic
- Sharing someone's private information without their consent
- Sustained disruptive behavior in discussions or reviews
- Any conduct that a reasonable person would consider inappropriate in a collaborative technical environment

## How Decisions Are Made

File Browser Next operates with a flat, contributor-based model. There are no fixed roles beyond maintainers who handle repository access and releases. Technical decisions are made through open discussion in issues and pull requests. Any contributor can propose a change — merit of the argument matters, not seniority.

## Reporting

If you witness or experience behavior that violates this code of conduct, you can report it to **contact@revlibertaire.com** or open a private issue on GitHub. Reports are handled confidentially on a best-effort basis. The maintainers are volunteers and cannot guarantee a formal response or outcome.

## Consequences

Depending on the severity and context of the violation, the response may range from a private conversation to a temporary or permanent removal from the project spaces. The goal is always to resolve the situation and keep the project healthy, not to punish.
